CI/CD Integration

Integrate Falcon into your continuous integration pipeline for automated analysis, PR comments, and quality gates.

1. GitHub Actions

Add Falcon to your GitHub Actions workflow. Below is a complete workflow that runs basic analysis, posts PR comments, and tracks AI score.

Create .github/workflows/falcon.yml:

name: Falcon Analysis

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]

jobs:
  falcon:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Install Rust
        uses: dtolnay/rust-action@stable

      - name: Install Falcon
        run: cargo install --git https://github.com/viveky259259/falcon

      - name: Run Falcon analysis
        run: falcon analyze . --fail-on error

      - name: Run AI score
        id: ai-score
        run: |
          falcon ai-score . --json > score.json
          SCORE=$(jq -r '.score' score.json)
          echo "score=$SCORE" >> $GITHUB_OUTPUT

      - name: Post PR comment
        if: github.event_name == 'pull_request'
        uses: actions/github-script@v7
        with:
          script: |
            const fs = require('fs');
            const report = fs.readFileSync('score.json', 'utf8');
            const data = JSON.parse(report);
            const body = `## Falcon Analysis
            **AI Score:** ${data.score}/100 (${data.grade})
            **Issues:** ${data.issues || 0} found
            `;
            github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body: body
            });

2. GitLab CI

Add Falcon to your GitLab CI pipeline. Example .gitlab-ci.yml with CodeClimate format output:

stages:
  - analyze

falcon:
  stage: analyze
  image: rust:latest
  before_script:
    - cargo install --git https://github.com/viveky259259/falcon
  script:
    - falcon analyze . --format codeclimate --output gl-codeclimate-report.json
  artifacts:
    reports:
      codequality: gl-codeclimate-report.json

3. PR Comment Bot

Use falcon pr-comment to post analysis results as a comment on pull requests.

How it works

The command runs Falcon analysis, formats the output as markdown, and posts it as a PR comment via the GitHub API. It can auto-detect context from GitHub Actions environment variables or accept explicit targeting.

Flags

  • --dry-run — Preview the comment without posting
  • --owner — Repository owner (e.g., myorg)
  • --repo — Repository name (e.g., myapp)
  • --pr — Pull request number

Auto-detection

When running in GitHub Actions, Falcon automatically uses GITHUB_REPOSITORY and GITHUB_EVENT_PATH to determine owner, repo, and PR number.

Example PR comment output

## Falcon Analysis

**AI Score:** 82/100 (B)

| Dimension | Score |
|-----------|-------|
| Maintainability | 78% |
| Testability | 85% |
| Performance | 82% |
| Security | 80% |
| Consistency | 92% |
| Documentation | 62% |

**Issues found:** 4
- 2 errors
- 2 warnings

Run Falcon locally: `falcon analyze .`

4. Webhook Integration

Use falcon webhook to send analysis events to external services.

Event types

  • analysis.complete — Analysis finished successfully
  • score.changed — AI score changed (e.g., from previous run)
  • drift.detected — Drift from conventions detected

Example command

$ falcon webhook --url https://hooks.example.com/falcon --event analysis.complete

Example payload (JSON)

{
  "event": "analysis.complete",
  "timestamp": "2025-03-18T10:30:00Z",
  "project": "/path/to/project",
  "results": {
    "errors": 2,
    "warnings": 5,
    "ai_score": 82,
    "grade": "B"
  }
}

5. Exit Codes

Falcon uses the following exit codes for CI integration:

CodeMeaning
0Pass — No errors (or no errors above the configured threshold)
1Errors found — One or more issues at error level
2Configuration or runtime error

Use --fail-on error to fail only on errors; use --fail-on warning to also fail on warnings.

6. Output Formats

Falcon supports multiple output formats for different CI and tooling integrations:

FormatUse case
consoleHuman-readable terminal output (default)
jsonMachine-readable JSON for scripts and pipelines
htmlHTML report for artifact storage or dashboards
sarifSARIF format for GitHub Code Scanning
codeclimateCodeClimate format for GitLab and other tools
checkstyleCheckstyle XML for Jenkins and similar
sonarSonarQube/SonarCloud import format
gitlabGitLab Code Quality report format

Example:

falcon analyze . --format sarif --output falcon-report.sarif
