Falcon Documentation

Falcon is a Rust-powered static analysis tool for Flutter and Dart projects. It helps you catch issues early, enforce best practices, and improve code quality with AI-assisted insights.

Quick Install

Install Falcon from source using Cargo:

cargo install --git https://github.com/viveky259259/falcon

Quick Start

Run the AI score command on your project to get an instant quality assessment:

falcon ai-score .

Example output:

$ falcon ai-score .
Analyzing project...
AI Score: 78/100
Suggestions: 3 improvements found
