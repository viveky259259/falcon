Falcon Documentation

Falcon is a Rust-powered static analysis and app management tool for Flutter/Dart. It analyzes code quality, enforces architecture, manages dependencies, predicts production risks, and integrates with AI tools — all in under 2 seconds.

Quick Install
cargo install --git https://github.com/viveky259259/falcon

Quick Start

$ falcon manage health .

Key Commands

CommandDescription
falcon analyzeFull static analysis (61+ rules) with auto-save to history
falcon analyze --format htmlEnterprise HTML report with dashboard, charts, and dark/light theme
falcon compare-branchesCompare two git branches side-by-side with delta report
falcon historyView all stored analysis runs
falcon compare-reportsCompare any two stored runs from history
falcon ai-scoreAI Code Quality Score with 6-dimension breakdown
falcon x codebase-intelHealth score, god files, hotspots, tech debt estimate
falcon manage healthUnified project health dashboard (0-100)
falcon updateSelf-update to latest or specific version
falcon mcpMCP server for AI tool integration
