Enterprise

Falcon Enterprise adds policies, audit logs, compliance reports, certification, and team cloud features for organizations.

1. Enterprise Policies

Use falcon x enterprise to define and enforce organizational policies across your projects.

Initialize policies

Run falcon x enterprise init to create default policies in your project:

$ falcon x enterprise init
Created .falcon-data/policies.json with 4 default policies

Default policies

Policy Description
min_ai_score Minimum AI quality score (default: 70)
max_critical_issues Maximum allowed critical issues (default: 0)
required_rules Rules that must pass (e.g., prefer_const, avoid_print)
ai_provenance_required Require AI-generated code to have provenance metadata

Check policies

Evaluate your project against policies with falcon x enterprise check:

$ falcon x enterprise check
Checking policies...

✓ min_ai_score        (72 >= 70)
✓ max_critical_issues (0 <= 0)
✓ required_rules      (all passed)
✗ ai_provenance_required (3 files missing provenance)

2 passed, 1 failed

Custom policies

Edit .falcon-data/policies.json to add custom policies. Example:

{
  "policies": [
    {
      "id": "custom_no_deprecated",
      "name": "No Deprecated APIs",
      "rule": "avoid_deprecated",
      "severity": "error"
    }
  ]
}

2. Audit Logs

Every Falcon action is recorded with timestamp, user, action, and target for compliance and traceability.

View audit log

Run falcon x enterprise audit to view recent actions:

$ falcon x enterprise audit
Timestamp              User      Action           Target
2025-03-18 10:23:01   alice     analyze           /projects/app
2025-03-18 10:22:45   bob       ai-score          /projects/app
2025-03-18 10:20:12   alice     fix               lib/main.dart
2025-03-18 10:18:00   bob       enterprise-check  /projects/app

3. Compliance Reports

Generate markdown compliance reports with falcon x enterprise compliance --output report.md.

Report contents

  • Policy evaluation results (passed/failed)
  • Audit log summary
  • Timestamps and run metadata

Example output

# Falcon Compliance Report
Generated: 2025-03-18 10:30:00

## Policy Results

4. Falcon Certification

Certify your project with falcon x certify. Certification levels are based on AI score thresholds.

Certification levels

Level Score
Bronze 60+
Silver 75+
Gold 85+
Platinum 95+

Criteria checked

Falcon evaluates 7 criteria: code quality, conventions, test coverage, documentation, security, performance, and maintainability.

Example output

$ falcon x certify
Certifying project...

Score: 87/100
Certification: Gold ✓

Criteria:
  ✓ Code quality
  ✓ Conventions
  ✓ Test coverage
  ✓ Documentation
  ✓ Security
  ✓ Performance
  ✓ Maintainability

Badge for README

Add a certification badge to your README:

![Falcon Certified](https://img.shields.io/badge/Falcon-Certified_Gold-gold)

5. Team Cloud

Manage multiple projects and team dashboards with falcon x cloud.

Initialize team

$ falcon x cloud init --team "My Team"
Team "My Team" initialized

Add projects

$ falcon x cloud add-project --name app --project-path /path/to/app
Project "app" added to team

Dashboard

$ falcon x cloud dashboard
Team: My Team
Projects: 3

| Project | Score | Last Run    | Status |
|---------|-------|-------------|--------|
| app     | 87    | 2 min ago   | ✓      |
| api     | 72    | 5 min ago   | ✓      |
| web     | 65    | 1 hour ago  | ⚠      |

Alert configuration

Configure alerts for score drops, policy failures, or critical issues via .falcon-data/cloud.json or the web dashboard.
