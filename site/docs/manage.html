App Management

Falcon goes beyond static analysis — it manages your Flutter app. The falcon manage command provides a unified dashboard covering project health, dependencies, architecture, maintenance, and build optimization.

Run everything at once
falcon manage all /path/to/flutter/app

Use --json to get machine-readable output for CI pipelines:

falcon manage health . --json

Architecture Governor

Detects your architecture pattern, enforces layer boundaries, and finds complexity hotspots.

$ falcon manage arch .

  falcon manage Architecture Governor

  Pattern:         Clean Architecture
  Compliance:      92%
  Violations:      3
  Modules:         45

  ▸ Violations:
    ✗ lib/domain/user_repo.dart — Domain layer imports from data layer
    ✗ lib/data/api_service.dart — Data layer imports from presentation

  ▸ Complexity Hotspots:
    ⚠ lib/pages/settings.dart — 1271 lines — split into smaller files
    ⚠ lib/pages/profile.dart — 810 lines — split into smaller files

  ▸ Suggestions:
    → 5 files exceed 500 lines — break into focused modules
    → Enforce with: falcon x check-layers in CI

Running All Analyses

Use falcon manage all to run health, deps, arch, maint, and build analyses in sequence:

$ falcon manage all /path/to/app

This gives you a complete picture of your Flutter app's state in a single command.

CI Integration

Add health checks to your CI pipeline:

# .github/workflows/falcon.yml
name: Falcon Health Check
on: [pull_request]
jobs:
  health:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: cargo install --git https://github.com/viveky259259/falcon
      - run: falcon manage health . --json > health.json
      - run: falcon pr-comment .
Tip

Combine falcon manage health with falcon x enterprise check to enforce minimum health scores as a CI gate.
