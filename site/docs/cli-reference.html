Detailed Command Reference

In-depth documentation for the five most important commands.

analyze

Run full static analysis on your Flutter/Dart project. This is the primary entry point for catching issues.

Full syntax:

falcon analyze [PATH] [OPTIONS]

Flags:

FlagDescription
--fixAuto-fix safe issues where possible
--strictEnable strict mode (treat warnings as errors)
--jsonOutput results in JSON format
--rulesComma-separated list of rules to run
--excludeGlob pattern to exclude files
--no-cacheDisable analysis cache

Example:

$ falcon analyze . --fix --json
{"issues": 12, "fixed": 3, "warnings": 9}

ai-score

Get an AI-powered quality score (0–100) for your project. Uses static analysis plus optional AI models for deeper insights.

Full syntax:

falcon ai-score [PATH] [OPTIONS]

Flags:

FlagDescription
--modelAI model to use (e.g., gpt-4, claude)
--verboseShow detailed breakdown of score
--no-aiUse heuristic-only scoring (no API calls)
--outputWrite report to file

Example:

$ falcon ai-score .
Analyzing project...
AI Score: 78/100
Suggestions: 3 improvements found

pr-comment

Post analysis results as a comment on a pull request. Integrates with GitHub, GitLab, and Bitbucket.

Full syntax:

falcon pr-comment [OPTIONS]

Flags:

FlagDescription
--tokenGit provider token (or GITHUB_TOKEN env)
--prPR number (auto-detected in CI)
--repoRepository (owner/repo)
--baseBase branch for diff
--headHead branch/commit
--updateUpdate existing comment instead of new

Example:

$ falcon pr-comment --token $GITHUB_TOKEN --pr 42
Posted analysis to PR #42
Issues: 5 | Warnings: 12 | Score: 82/100

mcp

Start the Model Context Protocol (MCP) server. Enables AI assistants like Cursor to query your codebase via Falcon.

Full syntax:

falcon mcp [OPTIONS]

Flags:

FlagDescription
--portPort for stdio/HTTP transport (default: 3000)
--stdioUse stdio instead of HTTP
--projectPath to project to analyze

Example:

$ falcon mcp --stdio --project .
MCP server listening on stdio
Ready for connections

enterprise check

Run enterprise compliance and policy checks. Validates licensing, security, and organizational standards.

Full syntax:

falcon enterprise check [PATH] [OPTIONS]

Flags:

FlagDescription
--policyPolicy file or preset to apply
--reportGenerate compliance report
--fail-onExit non-zero on specified severity
--jsonOutput in JSON format
--licenseValidate license compliance

Example:

$ falcon enterprise check . --report
Enterprise check complete
Compliance: PASS | Policy violations: 0
Report written to enterprise-report.md
