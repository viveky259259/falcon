Comparison & history

v0.2.0 — Falcon keeps analysis snapshots so you can list past runs, diff two stored runs, or compare two git branches side by side.

falcon history

List stored analysis runs for a project (timestamp, branch, files, health score, issues, commit).

$ falcon history /path/to/project

Snapshots are saved automatically after falcon analyze and falcon compare-branches.

falcon compare-reports

Compare two numbered runs from history and optionally write an HTML diff.

$ falcon compare-reports /path/to/project --run1 1 --run2 3
$ falcon compare-reports /path/to/project --run1 1 --run2 3 --output comparison.html
FlagDescriptionDefault
--run1Baseline run (1-based index)Second-to-last
--run2Comparison runLatest
--outputHTML comparison report pathNone (console only)

falcon compare-branches

Checks out each branch in turn, runs full analysis, restores your original branch, and produces a delta report.

$ falcon compare-branches /path/to/project --base main --branch feature/my-feature
$ falcon compare-branches . --base main --branch dev --output comparison.html
FlagDescriptionDefault
--baseBase branchRequired
--branchBranch to compareRequired
--outputHTML report pathfalcon-branch-comparison.html
--configPath to falcon.yamlAuto-detect

What the comparison shows

  • Health score delta with direction
  • File count, lines of code, and total issues delta
  • Error / warning / info breakdown
  • Metrics delta (e.g. complexity, maintainability, god files)
  • Top rule changes, new rules, and resolved rules

Both branch analyses are saved to history for later use with compare-reports. For the HTML analysis dashboard, see HTML Reports.
