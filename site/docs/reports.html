HTML Reports

v0.2.0 — Falcon can emit a self-contained HTML dashboard from falcon analyze, ideal for sharing results, archiving runs, and CI artifacts.

Generate a report

$ falcon analyze . --format html --output report.html

Default output path when omitted is falcon-report.html. See CLI Reference for --config, --since, --baseline, and --fail-on.

What’s in the report

  • Project properties from pubspec.yaml (name, version, SDK, dependencies)
  • Health score with an at-a-glance gauge
  • Level of concern breakdown (security, error handling, type safety, and related dimensions)
  • Severity distribution and top rules
  • Complexity hotspots and test coverage mapping (source ↔ test files)
  • Issues grouped by file with search and severity filters
  • Function and class metrics tables
  • Dark / light theme toggle in the generated page

Each successful falcon analyze also stores a snapshot under your project for history and comparison commands described on Branch Comparison.
