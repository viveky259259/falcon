Code Examples

avoid-empty-catch

Empty catch blocks silently swallow exceptions, making debugging difficult. Always handle or rethrow errors.

Bad

try {
  await fetchData();
} catch (e) {
  // empty — error is silently ignored
}

Good

try {
  await fetchData();
} catch (e, stackTrace) {
  logError(e, stackTrace);
  rethrow;
}

ensure-dispose-lifecycle

Controllers and subscriptions must be disposed to prevent memory leaks. Override dispose() and clean up resources.

Bad

class MyWidget extends StatefulWidget {
  final TextEditingController controller =
      TextEditingController();
  // Missing dispose — controller leaks
}

Good

class MyWidget extends StatefulWidget {
  final TextEditingController controller =
      TextEditingController();

  @override
  void dispose() {
    controller.dispose();
    super.dispose();
  }
}

avoid-unawaited-futures

Futures must be awaited to handle errors and ensure proper execution order. Unawaited futures can cause unhandled exceptions.

Bad

void saveData() {
  writeToFile(data);  // Future not awaited — errors lost
}

Good

Future<void> saveData() async {
  await writeToFile(data);
}
