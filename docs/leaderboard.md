# Falcon pub.dev Leaderboard

The Falcon leaderboard is a static weekly snapshot generated by GitHub Actions.
It has no browser-side calls to pub.dev: package metadata, package archives, and
Falcon score reports are collected during the scheduled build.

## Methodology

The weekly job fetches package names from pub.dev's official package-name
completion API, fetches score metadata for a configurable candidate window, then
selects the configured package count by granted pub points, likes, and package
name. The production schedule uses 500 packages.

For each selected package, the job downloads the latest package archive from the
official hosted pub repository API, verifies the archive SHA256 when pub.dev
provides one, runs `dart pub get` or `flutter pub get`, and then runs:

```bash
falcon score <package-dir> --json
```

The generated manifest is passed to:

```bash
falcon x leaderboard --input target/leaderboard/leaderboard-input.json --output site/leaderboard
```

The static generator writes `site/leaderboard/index.html` and one static package
score page under `site/leaderboard/packages/` for every scored package.

## Opt Out

Package maintainers can opt out by opening an issue in the Falcon repository
with the package name and ownership proof. Opted-out packages are removed from
the next generated snapshot by adding the package name to
`docs/leaderboard-opt-outs.txt`.

## Manual Rebuild

Maintainers can run a smoke rebuild with a smaller package count:

```bash
cargo build --release --bin falcon
python3 scripts/leaderboard/build_pubdev_leaderboard.py \
  --falcon-bin target/release/falcon \
  --limit 10 \
  --candidate-limit 100 \
  --workdir target/leaderboard \
  --manifest target/leaderboard/leaderboard-input.json \
  --site-output site/leaderboard
```
